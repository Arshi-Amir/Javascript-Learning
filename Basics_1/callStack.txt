CODE Example:

function one() {
    console.log("one");
    two();
}

function two() {
    console.log("2");
    three();
}

function three() {
    console.log("3");
}

one();
two();
three();


========================================================
                CALL STACK FLOW
========================================================

1️⃣ JavaScript starts
--------------------------------------------------------

        ┌─────────────────┐
        │     GLOBAL      │
        └─────────────────┘


2️⃣ Global calls one()
--------------------------------------------------------

        ┌─────────────────┐
        │      one()      │  ← Running
        ├─────────────────┤
        │     GLOBAL      │
        └─────────────────┘

        Output: one


3️⃣ one() calls two()
--------------------------------------------------------

        ┌─────────────────┐
        │      two()      │  ← Running
        ├─────────────────┤
        │      one()      │  ← Waiting
        ├─────────────────┤
        │     GLOBAL      │
        └─────────────────┘

        Output: 2


4️⃣ two() calls three()
--------------------------------------------------------

        ┌─────────────────┐
        │     three()     │  ← Running
        ├─────────────────┤
        │      two()      │  ← Waiting
        ├─────────────────┤
        │      one()      │  ← Waiting
        ├─────────────────┤
        │     GLOBAL      │
        └─────────────────┘

        Output: 3


5️⃣ three() finishes → POP
--------------------------------------------------------

        ┌─────────────────┐
        │      two()      │  ← Running
        ├─────────────────┤
        │      one()      │
        ├─────────────────┤
        │     GLOBAL      │
        └─────────────────┘


6️⃣ two() finishes → POP
--------------------------------------------------------

        ┌─────────────────┐
        │      one()      │  ← Running
        ├─────────────────┤
        │     GLOBAL      │
        └─────────────────┘


7️⃣ one() finishes → POP
--------------------------------------------------------

        ┌─────────────────┐
        │     GLOBAL      │
        └─────────────────┘


8️⃣ Global continues → two()
--------------------------------------------------------

        ┌─────────────────┐
        │      two()      │  ← Running
        ├─────────────────┤
        │     GLOBAL      │
        └─────────────────┘

        Output: 2


9️⃣ two() calls three()
--------------------------------------------------------

        ┌─────────────────┐
        │     three()     │  ← Running
        ├─────────────────┤
        │      two()      │
        ├─────────────────┤
        │     GLOBAL      │
        └─────────────────┘

        Output: 3


🔟 three() → POP
    two()   → POP
--------------------------------------------------------

        ┌─────────────────┐
        │     GLOBAL      │
        └─────────────────┘


1️⃣1️⃣ Global continues → three()
--------------------------------------------------------

        ┌─────────────────┐
        │     three()     │  ← Running
        ├─────────────────┤
        │     GLOBAL      │
        └─────────────────┘

        Output: 3


1️⃣2️⃣ three() → POP
--------------------------------------------------------

        ┌─────────────────┐
        │     GLOBAL      │
        └─────────────────┘

        Global finishes.

========================================================
                  MAIN CONCEPT
========================================================

                 CALL STACK

              ┌─────────────┐
              │   three()   │  ← LAST IN
              ├─────────────┤
              │    two()    │
              ├─────────────┤
              │    one()    │
              ├─────────────┤
              │   GLOBAL    │  ← FIRST IN
              └─────────────┘

              ↓ POP ORDER

              three()
                 ↓
              two()
                 ↓
              one()

        LIFO = Last In, First Out
